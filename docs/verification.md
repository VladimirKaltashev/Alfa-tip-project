## Исправление открытия с телефона по LAN HTTP

Воспроизведено на `http://192.168.2.105:5173/`: `TypeError: crypto.randomUUID is not a function` при создании черновика. Предыдущая проверка на localhost не выявляла эту ошибку.

Добавлен общий генератор UUID v4: нативный `randomUUID` при наличии, иначе `getRandomValues`. Он используется в черновиках, выводах и создании сотрудников. Формат ID и сохранённые данные не меняются. Общий экран ошибки теперь предлагает обновить страницу и не приписывает любую ошибку хранилищу.

Проверено после исправления:
- открытие той же LAN HTTP-ссылки без сброса данных;
- демооплата 175 ₽, успешный результат и появление +175 ₽ в кабинете официанта;
- новых ошибок/предупреждений в консоли нет;
- 15 тестов пройдено, включая генерацию UUID и цепочку черновик → платёж → вывод без `randomUUID`;
- production-сборка успешна.

## Обновление визуального оформления

Холодная серая палитра, белые поверхности, графитовые кнопки и красные акценты. В шапке один словесный логотип без отдельной буквы «А» и без значка демо. Карточки сотрудников показывают фото и цель во всех режимах распределения. Настройки заведения содержат редактируемую ссылку на карту. Старые данные дополняются новыми полями без сброса истории.

Демонстрационные портреты взяты из Random User Generator (https://randomuser.me/). Локальные файлы и ссылки на источники: `public/avatars/`, `public/avatars/sources.json`. Имена, роли и цели в приложении вымышлены и не описывают людей на фотографиях.
